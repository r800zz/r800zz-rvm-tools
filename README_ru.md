# R800ZZ RVM Tools

[English](README.md) | [Русский](README_ru.md) | [Español](README_es.md) | [ภาษาไทย](README_th.md) | [中文](README_zh.md) | [한국어](README_ko.md) | [日本語](README_ja.md)

R800ZZ RVM Tools преобразует обычные видеофайлы в видео, подходящие для прозрачного фона.

Для выделения человека на переднем плане используется **Robust Video Matting (RVM)**, а для декодирования и кодирования видео — **FFmpeg**.

[README , UNIX-подобные операционные системы(Linux , WSL , macOS)](README_sh_ru.md)

Поддерживаются два режима вывода:

- **MP4 с зелёным фоном** — создаёт H.264 MP4, в котором выделенный человек помещается на чисто зелёный фон.
- **WebM VP9 Alpha** — создаёт WebM VP9 с настоящим альфа-каналом.

Высокопроизводительная видеокарта не обязательна. Инструмент может работать только на CPU, однако ускорение на GPU способно значительно ускорить обработку RVM.

## Краткое руководство

- Предварительно установите Python и FFmpeg.

- При первом запуске выполните `install_python_packages_NVIDIA.bat`.

- Чтобы преобразовать видео в вариант с зелёным фоном, перетащите видеофайл на `R800ZZ_Make_Green_MP4_NVIDIA.bat`.

- Чтобы преобразовать видео в Alpha-прозрачность (WebM VP9), перетащите видеофайл на `R800ZZ_Make_WebM_Alpha_NVIDIA.bat`.

## Что такое RVM?

RVM означает **Robust Video Matting**.

RVM — это нейросетевая модель маттинга видео с людьми, предназначенная для отделения человека от фона с сохранением временной информации между кадрами.

Этот инструмент использует оригинальный проект RVM через PyTorch Torch Hub.

Исходный код RVM и предварительно обученная модель **не включены в этот репозиторий**. При необходимости они загружаются из оригинального проекта.

## Режимы вывода

### MP4 с зелёным фоном

Человек, выделенный RVM, помещается на чисто зелёный фон и кодируется в H.264 MP4.

Пример результата:

```text
aaa_RVM_Green.mp4
```

Этот режим предназначен для VR-видеоплееров, поддерживающих прозрачность через chroma key.

Примеры:

- [R800ZZbrowser для PICO/Meta](https://vr180g.com/browser/browser.php?l=ru)
- [r800zzvrplayer для PICO 4 Ultra/PICO4](https://vr180g.com/pico/vrplayer.php?l=ru)

Преобразование с зелёным фоном обычно значительно быстрее, чем преобразование в WebM VP9 Alpha.

При наличии поддержки инструмент использует аппаратное кодирование H.264:

| Оборудование | Инференс RVM | Кодировщик H.264 |
| --- | --- | --- |
| NVIDIA GPU | PyTorch CUDA | `h264_nvenc` |
| AMD GPU | PyTorch DirectML | `h264_amf` |
| Intel GPU / встроенная Intel GPU | PyTorch DirectML | `h264_qsv` |
| Только CPU | PyTorch CPU | `libx264` |

### WebM VP9 Alpha

Этот режим создаёт WebM-видео в формате VP9 с настоящим альфа-каналом.

Пример результата:

```text
aaa_RVM_Alpha.webm
```

Это **не собственный формат альфа-видео R800ZZ**.

VP9 — открытый видеокодек проекта WebM, а WebM поддерживает видео с альфа-каналом. Альфа-данные сохраняются с помощью механизма Alpha в WebM, а не путём размещения пользовательской маски в неиспользуемой области кадра.

Создаваемый этим инструментом WebM VP9 Alpha в настоящее время кодируется FFmpeg `libvpx-vp9`. Этап кодирования VP9 Alpha выполняется на CPU, даже если инференс RVM работает на GPU. Поэтому преобразование в WebM VP9 Alpha может быть заметно медленнее преобразования в MP4 с зелёным фоном.

### VR-плееры, поддерживающие вывод

Примеры VR-плееров с функцией chroma key для MP4 с зелёным фоном:

- [R800ZZbrowser для PICO/Meta](https://vr180g.com/browser/browser.php?l=ru)
- [r800zzvrplayer для PICO 4 Ultra/PICO4](https://vr180g.com/pico/vrplayer.php?l=ru)

Для WebM VP9 Alpha подтверждён следующий VR-плеер:

- **[r800zzvrplayer 0.5 или новее](https://vr180g.com/pico/vrplayer.php?l=ru)**

На момент написания мне не удалось подтвердить другой VR-видеоплеер, который напрямую воспроизводит WebM VP9 и использует его альфа-канал как прозрачность в VR.

Это не означает, что других совместимых VR-плееров не существует. Если вы знаете такой плеер, пожалуйста, сообщите мне.

## Требования

- Windows 10 или Windows 11
- Python
- FFmpeg
- Доступ в Интернет во время начальной настройки и первого запуска RVM
- CPU или поддерживаемая NVIDIA / AMD / Intel GPU

Для максимальной совместимости с прилагаемыми скриптами настройки NVIDIA, AMD и Intel рекомендуется **Python 3.10–3.12**.

## Установка

### 1. Установите Python

Установите Python для Windows.

Сам Python **не устанавливается автоматически R800ZZ RVM Tools**.

Во время установки Python рекомендуется включить опцию добавления Python в `PATH`.

Проверить установку можно из командной строки:

```bat
python --version
```

### 2. Установите FFmpeg

FFmpeg не включён в этот репозиторий.

Скачайте сборку FFmpeg для Windows, содержащую как минимум:

- `ffmpeg.exe`
- `ffprobe.exe`
- `libvpx-vp9`
- `libopus`
- `libx264`

Для GPU-ускоренного создания MP4 с зелёным фоном сборка FFmpeg должна также содержать кодировщик для вашей GPU:

- NVIDIA: `h264_nvenc`
- AMD: `h264_amf`
- Intel: `h264_qsv`

Самый простой вариант — поместить:

```text
ffmpeg.exe
ffprobe.exe
```

в ту же папку, где находятся:

```text
r800zz_rvm_video.py
```

и BAT-файлы.

В такой конфигурации **не требуется** настраивать переменную среды Windows `PATH` для FFmpeg.

В качестве альтернативы FFmpeg можно установить в другое место и добавить его каталог `bin` в `PATH`.

Доступные аппаратные кодировщики можно проверить командой:

```bat
ffmpeg -encoders
```

### 3. Установите PyTorch для вашего оборудования

PyTorch не входит в этот репозиторий.

BAT-файлы настройки загружают необходимые Python-пакеты из их официальных источников.

Выберите способ установки, соответствующий вашему оборудованию.

#### NVIDIA GPU

Запустите:

```text
install_python_packages.bat
```

Это установит или обновит PyTorch с поддержкой CUDA, используемый обычными BAT-файлами NVIDIA/CPU.

Установленные пакеты помещаются в среду Python, на которую указывает команда `python`, обычно в:

```text
Lib\site-packages
```

внутри этой установки Python.

Путь NVIDIA GPU — это GPU-конфигурация, протестированная R800ZZ.

#### AMD GPU

Запустите:

```text
install_python_packages_AMD.bat
```

Будет создана отдельная виртуальная среда Python:

```text
.venv_amd
```

в папке R800ZZ RVM Tools, и в неё будет установлен `torch-directml`.

Для преобразования используйте BAT-файлы, заканчивающиеся на:

```text
_AMD.bat
```

Поддержка AMD GPU реализована через DirectML. R800ZZ не тестировал её на физическом оборудовании AMD.

#### Intel GPU / встроенная Intel GPU

Запустите:

```text
install_python_packages_Intel.bat
```

Будет создана отдельная виртуальная среда Python:

```text
.venv_intel
```

в папке R800ZZ RVM Tools, и в неё будет установлен `torch-directml`.

Для преобразования используйте BAT-файлы, заканчивающиеся на:

```text
_Intel.bat
```

Поддержка Intel GPU реализована через DirectML, а для MP4 с зелёным фоном при наличии поддержки используется Intel Quick Sync Video (`h264_qsv`).

R800ZZ не тестировал этот вариант на физическом оборудовании Intel.

#### Только CPU

GPU не требуется.

Для среды только с CPU установите CPU-версию PyTorch:

```bat
python -m pip install --upgrade pip
python -m pip install numpy
python -m pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
```

Стандартные BAT-файлы преобразования автоматически используют CPU, если CUDA недоступна.

Преобразование на CPU обычно медленнее инференса RVM с GPU-ускорением.

## Куда загружаются PyTorch и RVM?

### PyTorch

В обычной среде NVIDIA/CPU PyTorch устанавливается в среду Python, используемую командой `python`.

Например, стандартная установка Python может хранить пакеты по адресу:

```text
C:\Users\<username>\AppData\Local\Programs\Python\Python3xx\Lib\site-packages
```

Точное расположение зависит от способа установки Python.

Для AMD и Intel прилагаемые скрипты используют локальные виртуальные среды:

```text
R800ZZ_RVM_Tools\.venv_amd
R800ZZ_RVM_Tools\.venv_intel
```

### RVM

RVM загружается через PyTorch Torch Hub.

При первом преобразовании Torch Hub автоматически скачивает репозиторий RVM и предварительно обученную модель MobileNetV3.

Кэш Torch Hub по умолчанию в Windows обычно находится по адресу:

```text
C:\Users\<username>\.cache\torch\hub
```

Кэш репозитория RVM обычно появляется внутри этого каталога.

Загруженные веса модели обычно сохраняются в:

```text
C:\Users\<username>\.cache\torch\hub\checkpoints
```

Точное расположение кэша можно изменить настройками среды PyTorch, например `TORCH_HOME`.

После загрузки файлы из кэша повторно используются при последующих преобразованиях.

## Как использовать

Преобразование выполняется **перетаскиванием видеофайла на соответствующий `.bat` файл в Проводнике Windows**.

Например, если у вас есть:

```text
aaa.mp4
```

и вы хотите создать MP4 с зелёным фоном с помощью NVIDIA GPU или CPU, перетащите:

```text
aaa.mp4
```

прямо на:

```text
R800ZZ_Make_Green_MP4.bat
```

BAT-файл получает перетащенный видеофайл и автоматически запускает преобразование.

Аналогично, чтобы создать WebM VP9 Alpha, перетащите:

```text
aaa.mp4
```

на:

```text
R800ZZ_Make_WebM_Alpha.bat
```

Не нужно открывать командную строку и вручную вводить имя видеофайла.

### Создание MP4 с зелёным фоном

Для NVIDIA GPU или CPU перетащите видеофайл на:

```text
R800ZZ_Make_Green_MP4.bat
```

Для AMD GPU:

```text
R800ZZ_Make_Green_MP4_AMD.bat
```

Для Intel GPU:

```text
R800ZZ_Make_Green_MP4_Intel.bat
```

Пример:

```text
aaa.mp4
    ↓ перетащить
R800ZZ_Make_Green_MP4.bat
```

Результат:

```text
aaa_RVM_Green.mp4
```

### Создание WebM VP9 Alpha

Для NVIDIA GPU или CPU перетащите видеофайл на:

```text
R800ZZ_Make_WebM_Alpha.bat
```

Для AMD GPU:

```text
R800ZZ_Make_WebM_Alpha_AMD.bat
```

Для Intel GPU:

```text
R800ZZ_Make_WebM_Alpha_Intel.bat
```

Пример:

```text
aaa.mp4
    ↓ перетащить
R800ZZ_Make_WebM_Alpha.bat
```

Результат:

```text
aaa_RVM_Alpha.webm
```

По умолчанию BAT-файлы сохраняют преобразованное видео в папку R800ZZ RVM Tools.

## Примечания о производительности

GPU-ускорение является необязательным.

Текущий конвейер обработки состоит из нескольких этапов, и не все они ускоряются на GPU.

### NVIDIA

- Инференс RVM: CUDA GPU
- Кодирование H.264 MP4 с зелёным фоном: NVENC
- Кодирование WebM VP9 Alpha: CPU (`libvpx-vp9`)
- Декодирование входного видео FFmpeg: CPU в текущей реализации

### AMD

- Инференс RVM: DirectML
- Кодирование H.264 MP4 с зелёным фоном: AMF
- Кодирование WebM VP9 Alpha: CPU (`libvpx-vp9`)
- Декодирование входного видео FFmpeg: CPU в текущей реализации

### Intel

- Инференс RVM: DirectML
- Кодирование H.264 MP4 с зелёным фоном: Quick Sync Video
- Кодирование WebM VP9 Alpha: CPU (`libvpx-vp9`)
- Декодирование входного видео FFmpeg: CPU в текущей реализации

Поскольку кодирование WebM VP9 Alpha выполняется на CPU, очень быстрая GPU не ускоряет весь процесс Alpha-преобразования в той же степени.

MP4 с зелёным фоном может значительно сильнее выиграть от GPU-ускорения, поскольку и инференс RVM, и кодирование H.264 могут выполняться аппаратно на GPU.

## Примечания о качестве маттинга

RVM не удаляет фон на основе проверки определённого цвета.

Он оценивает передний план человека и альфа-маску с помощью нейронной сети.

Поэтому исходное видео не обязано иметь зелёный фон.

В режиме MP4 с зелёным фоном сначала выполняется маттинг человека с помощью RVM, после чего выделенный передний план помещается на заново созданный зелёный фон.

В режиме WebM VP9 Alpha альфа-маска RVM напрямую используется как информация о прозрачности выходного видео.

Результат может зависеть от исходного видео, движения, деталей волос, перекрытий, освещения и точности RVM.

## Статус тестирования оборудования

R800ZZ протестировал путь NVIDIA GPU.

Поддержка ускорения AMD GPU и Intel GPU включена, однако R800ZZ лично не тестировал эти варианты на физических системах с AMD или Intel GPU.

Для работы только на CPU дискретная GPU не требуется.

## Стороннее программное обеспечение

R800ZZ RVM Tools использует или работает со следующими проектами:

- Robust Video Matting
- PyTorch
- Torch-DirectML
- FFmpeg

RVM разрабатывается отдельно от R800ZZ RVM Tools.

Этот репозиторий не содержит исходный код RVM или файлы предварительно обученной модели.

## Отказ от ответственности

R800ZZ RVM Tools — независимая утилита.

Совместимость выходных файлов зависит от возможностей видеоплеера, используемого для воспроизведения.

Для MP4 с зелёным фоном требуется плеер с поддержкой chroma key.

Для WebM VP9 Alpha требуется плеер, который действительно декодирует и использует альфа-канал WebM. Поддержка обычного WebM VP9 не обязательно означает поддержку прозрачности VP9 Alpha.
